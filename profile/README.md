### About

**Team PJ** is a software company started in 2026 by two student founders. Our goal: to turn new possibilities into reality with innovative technology, and to create real value for the world.<br>
**Team PJ**는 2026년에 두 학생 창업자가 시작한 소프트웨어 회사입니다. 혁신적인 기술로 새로운 가능성을 현실로 만들고, 세상에 실질적인 가치를 창출하는 것이 목표입니다.

### Product

**[Interlock](https://github.com/TEAM-PJ-LAB/interlock-demo)**<br>
Run many AI coding agents on one codebase without them overwriting each other: symbol-level claims, edit / commit / merge enforcement, and every decision explained. Pre-release; to use it, email pj.southkorea@gmail.com.<br>
여러 AI 코딩 에이전트가 하나의 코드베이스에서 서로의 작업을 덮어쓰지 않게 해주는 도구. 정식 출시 전이며, 사용을 원하시면 pj.southkorea@gmail.com으로 연락해 주세요.
